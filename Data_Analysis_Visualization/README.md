# Data Analysis and Visualization Using Python

## Project Description
This project focuses on analyzing student performance data using Python libraries such as Pandas, NumPy, and Matplotlib.

## Objectives
- Load and explore datasets using Pandas.
- Perform numerical calculations using NumPy.
- Identify and handle missing values.
- Check and remove duplicate records.
- Analyze student performance.
- Visualize data using charts.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- VS Code

## Dataset
The dataset contains information about 10 students, including:
- Student ID
- Student Name
- Python Marks
- Java Marks
- Data Science Marks
- Attendance Percentage

## Data Analysis
The program calculates:
- Average marks in each subject.
- Highest and lowest marks.
- Overall average marks.
- Missing values.
- Duplicate records.

## Data Visualization
Three charts are created:

1. Bar Chart – Displays average marks by subject.
2. Line Chart – Displays student performance in Python.
3. Pie Chart – Displays student attendance distribution.

## How to Run the Project

1. Install Python.
2. Install the required libraries:

   pip install pandas numpy matplotlib

3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python data_analysis.py
