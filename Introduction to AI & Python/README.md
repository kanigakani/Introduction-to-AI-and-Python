# Introduction to AI & Python

## Project Overview
This project provides a beginner-friendly introduction to Artificial Intelligence (AI), Machine Learning (ML), Deep Learning (DL), and Python programming.

## Objectives
- Learn the basics of Artificial Intelligence.
- Understand the difference between AI, ML, and Deep Learning.
- Explore real-world AI applications.
- Install Python and understand basic programming concepts.
- Develop beginner-friendly Python programs.

## Technologies Used
- Python
- Visual Studio Code
- Markdown

## Python Programs

### 1. Simple Calculator
Performs addition, subtraction, multiplication, and division using functions.

### 2. Even or Odd
Checks whether a number is even or odd using if-else statements.

### 3. Factorial
Calculates the factorial of a number using loops.

### 4. Palindrome Checker
Checks whether a word reads the same forward and backward.

### 5. Number Guessing Game
A simple game using random numbers, loops, and conditions.

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run a program using:

python 05_Python_Programs/calculator.py

Replace calculator.py with another program filename to run a different program.
